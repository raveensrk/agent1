# agent1 prompts

Prompt templates. pi loads every other file in this folder as a slash command
named after the file, so the files keep their names (hyphens and all); this page
lists them in reading order and is itself left out of pi's prompts.

## Contents

1. [Agent brief header](agent_brief_header.md) - the safety, git, test and
   report rules put at the top of every brief to a subagent.
2. [Prompts](prompts.md) - a personal paste-bin of chat prompts; agents do not
   treat it as rules.
3. [Auto-install git hook](auto_install_git_hook.md) - keep one repo's GUI apps
   installed after commits and pulls, with hooks local to that repo.
4. [Convert to shared core apps](convert-to-shared-core-apps.md) - migrate an
   app to a shared core with a CLI and a macOS GUI.
5. [Testing infrastructure](testing-infrastructure-e2e.md) - build end-to-end
   tests that drive the real app.
6. [Tarot card](tarot-card.md) - an image prompt: a Rider-Waite style card of
   me.

Retired prompts are in the archive.
