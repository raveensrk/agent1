# agent1 design

This is agent1's bible: the design document. It says what agent1 is, what each
part does and why, in enough detail that an agent could build agent1 again from
these pages alone. It names no language or build tool; where a part has a
contract (a file format, a header, an exit code) the contract is given in full.

How to use agent1 day to day is in the [manual](../manual/README.md). The rules
themselves are in [rules](../rules/README.md).
