# agent1 notes

Working notes: research, history, measurements and personal lists that are
neither design nor manual. Agents do not treat them as rules. The files keep
their names, because other repos link to them; this page lists them in reading
order.

## Contents

01. [General](general.md) - loose findings about agents and formats.
02. [AI starter pack](ai_starter_pack.md) - the basics to learn first.
03. [Use case](use_case.md) - what I use agents for.
04. [Dev tools](dev_tools.md) - preferred dev tools, in order, with tags and a
    learning path (the Needs lines); read before choosing a tool.
05. [Models and harnesses](model_and_harness.yaml) - model recommendations, and
    dated harness reviews and ratings. The shareable HTML page is built from it.
06. [Model usage history](model_usage_history.md) - recorded models across agent
    harnesses.
07. [Subscription plan](subscription_plan.md) - plans, prices and measured spend.
08. [Question types](question_types.md) - question formats for vibe coding, AI
    and non-AI.
09. [Terminologies](terminologies.md) - prompt vocabulary to copy into prompts.
10. [Self improvement](self_improvement.md) - one line per way to improve
    agent1, found by Optimus Prime at the end of a task.
11. [WireGuard VPN on Vultr](wireguard_vpn_on_vultr.md) - a personal WireGuard
    VPN on a Vultr instance for iOS and macOS.
12. [No AI policy](policies/no_ai_policy.md) - links on AI-free policies, with
    [a plain-text copy](policies/no_ai.txt).

Also here, not chapters: [a multi-agent shell example](multi_agent_simple_example.sh)
