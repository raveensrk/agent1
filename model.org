** Reviews
Personal assessments of the AI models I use. Dated notes, newest first.
These assessments are not benchmark results or agent behavior instructions.

*** Rules
- Always give the full, correct model name along with its reasoning effort throughout this file. Verify both before adding or updating entries; show effort separately from the model name. If effort is unknown or not applicable, say so rather than guessing.
- Use the same readable name for each model in recommendations, reviews, and usage history. Preserve source identifiers separately in the Recorded ID column.
- Keep dated journal entries newest first (descending date order). Include the full model name, version, and reasoning effort in each entry heading; mark unknown versions or effort explicitly. Include the rating in each heading as [7], with the scale understood to be out of 10; use [unrated] when missing.
- One headline tag per model - the single most defining trait; omit the tag when unknown.
- Keep model name, version, reasoning effort, and rating in the heading only; do not duplicate them in properties. Write reviews and notes directly beneath each model heading, including harness, task context, assessment, and reuse decision. Do not create separate Review or Verdict headings.

*** Rating Scale
Ratings are out of 10; intermediate scores are allowed. Existing out-of-5 ratings have been doubled. Missing ratings remain unrated.

| Rating | Label | Meaning                                           |
|--------+-------+---------------------------------------------------|
| 10/10  | best  | Best in class. First pick for this kind of work.  |
| 8/10   | good  | Strong. Reliable, minor gaps.                     |
| 6/10   | mid   | Usable. Gets the job done with some supervision.  |
| 4/10   | bad   | Weak. Needs heavy correction or a fallback model. |
| 2/10   | worst | Avoid for this kind of work.                      |
