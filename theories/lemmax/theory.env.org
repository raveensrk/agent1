#+title: Environment of lemmax
#+SETUPFILE: setup.org
What a rebuild of lmx needs besides its code. Versions are the ones in use on 2026-11-22; the tests also run on Emacs 29.

* Toolchain
** Emacs
:PROPERTIES:
:VERSION: 31.1
:END:
Runs lmx and its ERT tests; Emacs 29 or newer.
** git
:PROPERTIES:
:VERSION: 2.56.1
:END:
** bash
:PROPERTIES:
:VERSION: 5.3.20
:END:
Runs the launcher, =run_tests= and =install=; =run_tests= needs 5 or newer.
** python3
:PROPERTIES:
:VERSION: 3.15.2
:END:
Runs the harness check =harness/checks/lemmax_lint.py=.

* Data
** None
lmx reads only the repo it runs in; tests build their own repos under =$TMPDIR=.

* Setup
** Put lmx on PATH
=bash lemmax/install= writes =~/.local/bin/lemmax=.
** Put lmx in a repo's hooks
=lmx install-hooks= in the repo, for =pre-commit= and =commit-msg=.
