#+title: Environment of lemmax
What a rebuild of lemmax needs besides its code. Versions are the ones in use on 2026-11-22; the tests also run on Emacs 29.

* Toolchain
** Emacs
:PROPERTIES:
:VERSION: 31.1
:END:
Runs lemmax and its ERT tests; Emacs 29 or newer.
** git
:PROPERTIES:
:VERSION: 2.56.1
:END:
** bash
:PROPERTIES:
:VERSION: 5.3.20
:END:
Runs the launcher, =run_tests= and =install=.
** perl
:PROPERTIES:
:VERSION: 5.34.1
:END:
=run_tests= stops a test over its time with it.
** python3
:PROPERTIES:
:VERSION: 3.15.2
:END:
Runs the harness check =harness/checks/lemmax_lint.py=.

* Data
** None
lemmax reads only the repo it runs in; tests build their own repos under =$TMPDIR=.

* Setup
** Put lemmax on PATH
=bash requirements/scripts/lemmax/install= writes =~/.local/bin/lemmax=.
** Put lemmax in a repo's hooks
=lemmax install-hooks= in the repo, for =pre-commit= and =commit-msg=.
