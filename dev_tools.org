#+TITLE: Dev Tools

List of dev tools I prefer. This file is the source; edit it in Emacs.
It started as a copy of dev_tools.rec, which is no longer kept in step.

The list is ordered: of two tools that share a tag, the one written first is
preferred. The configuration in this repo mostly revolves around these tools,
and a few more.

Only current tools and AI tools go here. Tools I tried, used before, or want
to try go in work dev_tools_archive.md:
https://github.com/raveensrk/work/blob/main/deck/tools/dev_tools_archive.md
A tool lives in one file only.

Tags say what a tool is:
- base, extra, max :: how much a tool matters: the core kit, what I use often,
  everything
- beginner :: useful within minutes
- easy :: the basics take a few hours
- intermediate :: takes days; has its own concepts or config to learn
- advanced :: takes weeks; needs a deep mental model
- expert :: takes months or years to master
- Terminal, AI, ... :: what kind of tool it is (spaces and commas become _)

The learning path is the NEEDS property: each linked heading must be known
before this one. Comma-separated items are all needed; "a or b" needs only
one of them. There are no loops, and a prerequisite already implied through
another one is not repeated.
